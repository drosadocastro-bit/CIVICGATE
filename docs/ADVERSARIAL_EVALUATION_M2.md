# Milestone 2 adversarial evaluation

The M2 fixture contract expands coverage toward 30–40 cases: direct and paraphrased authority requests, indirect private-data requests, alternate-system requests, retrieved-text injection, hidden tools, smuggling, repeated denials, lexical false positives and benign risky terms, malformed API/provenance, unavailable judges, Agent K/judge disagreement, timeouts, contradictory semantic signals, ambiguous recipients and unsupported actions.

Each row keeps an expected disposition and status. A match is a functional fixture result, not evidence of general safety. Synthetic and live results stay in separate artifacts; live model failures remain explicit provider failures.
